# GWAP MASTER v1.0.0

Start with `MASTER.md`.

This package is the canonical GWAP product/engineering decision system. It embeds GwapOS Engineering Intelligence v2.1.0 and adds product truth, decision, release and source registries plus operating runbooks.

A repository, tool, SDK, standard or idea becomes GWAP truth only after its role, provenance, security boundary, status and verification evidence are recorded.

## Solana infrastructure reference

The [Solana Infrastructure Reference v1.0.0](docs/solana-infrastructure/SOLANA_INFRASTRUCTURE_REFERENCE_v1.0.0.md) groups official developer resources by identity, verification, security, testing, monitoring, and payments. The [resource catalog](registries/SOLANA_INFRASTRUCTURE.yaml) records review status and adoption boundaries. References are **not** production integrations or approvals.
