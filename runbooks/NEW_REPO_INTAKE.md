# New Repository Intake

1. Identify repo/owner/default branch/maintenance state.
2. Determine canonical implementation vs mirror/directory/fork/example/template/spec/historical source.
3. Pin exact reviewed commit/tag.
4. Review license before copying code.
5. Review security/audit claims and scope.
6. Define concrete capability GWAP could gain.
7. Identify overlap/conflict with existing architecture.
8. Classify status.
9. Add only useful boundaries/patterns.
10. Record re-review triggers.

Executable third-party agent skills must pass existing skill-security intake before installation.
