# Decision Workflow

1. State the user/product outcome.
2. Identify the owning GWAP subsystem.
3. Inspect current repository and deployed reality.
4. Find the highest-authority applicable sources.
5. Pin source commit/tag/version.
6. Compare alternatives; do not force a fashionable stack change.
7. Define security/authority/value boundary.
8. Choose smallest correct implementation.
9. Define test and acceptance evidence before coding.
10. Implement and verify.
11. Record the decision and evidence.
12. Promote status only when evidence supports it.
